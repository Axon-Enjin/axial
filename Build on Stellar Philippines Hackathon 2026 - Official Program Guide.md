# **Build on Stellar Philippines Hackathon 2026: Official Program Guide**

The Build on Stellar Philippines Hackathon 2026 is a 7-day online builder-first event. It is designed to empower the next generation of Filipino fintech innovators to ideate, build, and pitch MVPs that tackle real financial challenges using the Stellar blockchain.

# **Event Overview**

* **Dates:** May 18–24, 2026  
* **Format:** 100% Online (with an in-person Demo Day)  
* **Eligibility:** Open to developers, designers, founders, and students (Teams of 1–5)  
* **Experience Level:** All levels welcome; no prior blockchain experience required

# **Why Build on Stellar?**

Stellar is a blockchain purpose-built for real-world financial use cases.

| Feature | Why It Matters |
| :---- | :---- |
| Fast & Low-Cost | Transactions settle in 3–5 seconds for a fraction of a cent. |
| Cross-Border | Built for global payments across currencies. |
| Financial Inclusion | Designed for the unbanked and underserved. |
| Asset Tokenization | Tokenize real-world assets like invoices and commodities. |
| Emerging Markets | Powering fintech solutions across Southeast Asia. |

# **Hackathon Theme & Focus Areas**

The theme is **Real-World Financial Solutions for Filipinos**, focusing on improving how money moves and is accessed by OFWs, MSMEs, and unbanked communities.

* **Payments & Remittances:** Faster money transfers for OFWs.  
* **Financial Inclusion:** Wallets and tools for the unbanked.  
* **Stablecoins & PayFi:** Programmable payment finance solutions.  
* **MSME & Commerce Tools:** Invoicing, payroll, and cashflow for small businesses.  
* **Developer Tools:** SDKs and infrastructure for the Stellar ecosystem.

| Award | Prize |
| :---- | :---- |
| 1st Place | ₱25,000 |
| 2nd Place | ₱15,000 |
| 3rd Place | ₱10,000 |
| Consolation (x2) | ₱5,000 each for best use of Stellar |

# **Submission Requirements**

Each team must submit the following by May 23–24, 2026:

* **GitHub Repository:** Clean, documented codebase with a complete README.  
* **Demo Video:** 2–3 minute walkthrough of the working product.  
* **Pitch Deck:** Maximum 10 slides.  
* **Working MVP:** Must be deployed on both Stellar Testnet and Mainnet (XLM provided for costs).
